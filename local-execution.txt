## 🚀 Local Execution Instructions (WSL / Linux)

## Step 1: Run the cpp-server
    1. Navigate to the project root:
    cd Drive-Project

    2. Create build directory and compile (if not already done):
    mkdir -p build && cd build
    cmake ..
    make

    3. Run the server on port 8080:
    ./server_app 8080


## Step 2: run the web-server
    1. Open a new terminal and navigate to the web-server folder:
    cd Drive-Project/web-server

    2. Install dependencies (first time only):
    npm install

    3. Start the server:
    node app.js

## Step 3: run the react client
    1. Open a new terminal and navigate to the client folder:
    cd Drive-Project/client-react

    2. Install dependencies (first time only)
    npm install

    3. Start the application
    npm start
