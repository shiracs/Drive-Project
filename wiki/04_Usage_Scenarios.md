# Demos & Usage

Here is a guide on how to use the main features of the system and see the synchronization in action.

## 1. Register & Login
Users are saved in the database, so you can create a user on the website and log in with the same user on the mobile app.

### Step 1: Register (Web)
1.  Open your browser and go to `http://localhost:3000`.
2.  Click on the "Register" button.
3.  Enter a username and password to create a new account.

![Screenshot of Web Registration Page]

### Step 2: Login (Mobile)
1.  Open the app on your phone.
2.  Enter the same username and password you just created.
3.  Tap "Login".

![Screenshot of Mobile Login Screen]

## 2. File Sync Demo (Upload & View)

### Upload a File (Web)
1.  Go to the website dashboard.
2.  Click the **Upload** button.
3.  Choose a picture or a text file from your computer.
4.  The file is now uploaded and saved on the server.

![Screenshot of Web Dashboard with the new file]

### View the File (Mobile)
1.  Go to the mobile app on your phone.
2.  Refresh the list (pull down to refresh).
3.  You will see the file you just uploaded from the computer!

![Screenshot of Mobile File List showing the uploaded file]

### Delete a File
1.  Click the **Delete** (Trash icon) button next to a file on the mobile app.
2.  Refresh the website on your computer.
3.  The file will be gone there too. This proves the system is fully synced.

![Screenshot showing the file has been deleted]
